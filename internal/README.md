# Internal Surfaces

This directory holds project-internal working materials that are useful during framework and product development but are not part of the clean agnostic VIBE release surface by default.

Examples:
- audit reports
- inventory reports
- migration notes
- temporary review artifacts

Rule:
- keep canonical VIBE methodology artifacts in their public contract locations
- move internal reviews, working journals, and repo-maintenance reports here
- do not let internal notes become a second source of truth
